# AGENTS.md

## Commits (jj)

- Scope first, no types: `<scope>: <short description>` — e.g. `tickets: implement MVP from spec`.
- Do not use Conventional Commits prefixes (`feat:`, `fix:`, `chore:`, `docs:`, …).
- The scope names the area touched: `tickets`, `spec`, `ui`, `pdf`, `server`, `tests`.
- Commit with `jj describe`; never create or describe commits without the user's go-ahead.
